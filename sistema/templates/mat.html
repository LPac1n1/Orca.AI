1. Pesquisa automática

{{ selo('info', NOME_TIPO[tipo]) }}
O sistema procura o mesmo produto em 3 lojas e mostra uma proposta para você aprovar. O que já está comprovado não é refeito. Modo: {{ 'cada item com as suas 3 lojas' if p.config.modo_cesta == 'por_item' else 'as mesmas 3 lojas para a rubrica' }} · IA: {{ 'ligada' if (p.config.usar_ia and ia_ok) else 'desligada' }}.
Como a pesquisa funciona
O sistema procura o mesmo produto em 3 lojas de empresas diferentes (as mais baratas), confere estoque e preço no CEP {{ p.cep or '(informe o CEP na configuração do projeto)' }} e mostra uma proposta para você aprovar antes de gravar. Se o produto não existir em 3 lojas, ele propõe uma troca (o mesmo produto de outra marca, um produto parecido ou da mesma categoria, sempre o MESMO nas 3 lojas) e explica o motivo. O que já está com as 3 pesquisas comprovadas não é refeito; as pesquisas sem comprovante o sistema tenta resolver sozinho (de novo na mesma loja ou em outra loja com o mesmo produto). O que você escreveu nesta tela é salvo antes de pesquisar. Para pesquisar um item só, abra o item e use "Pesquisar de novo só este item".
