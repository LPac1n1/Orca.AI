Base oficial do CNPJ (Receita Federal)

É uma cópia do cadastro público de empresas, guardada neste computador (fora do OneDrive). O sistema usa a base para achar o CNPJ de quem anunciou a vaga, conferir se a empresa está ativa e saber se existe outra empresa com o mesmo nome. A Receita publica dados novos uma vez por mês; o sistema verifica todo dia e atualiza sozinho.
