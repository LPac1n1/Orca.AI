Primeira vez aqui? Veja como funciona

  1. Crie o projeto

    Informe o nome e o teto (o valor total que o orçamento precisa fechar).

  2. Cadastre os itens do plano

    Os cargos (mão de obra) e as rubricas de materiais e serviços, com os itens de cada uma.

  3. Clique em "Pesquisar tudo"

    O sistema procura 3 vagas para cada cargo e 3 preços para cada item, confere os CNPJs e guarda os comprovantes em PDF.

  4. Confira, feche no teto e baixe o pacote

    A tela do projeto mostra o que falta. No fim, um arquivo .zip traz as planilhas e os comprovantes de cada rubrica, prontos para a Secretaria.

Mais explicações, com o significado de cada palavra das telas, em Ajuda.
